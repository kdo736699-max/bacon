# 培根的房间

**你好，我是赵培涵，也可以叫我培根 Bacon。**

对人的生活有好奇，把发现变成行动。

这是我的个人网站，也是一间可以推门走进去的房间。我把做过的项目、写过的内容、研究过的问题，以及工作之外的自己，放在这里。

## 关于我

本科就读于华东理工大学公共事业管理专业，目前在华东师范大学攻读社会工作硕士，预计 2027 年 7 月毕业。

我做过社区运营、内容传播和公益项目，也做社会科学研究与一些小产品。这些经历有一个共同的起点：**理解一个人为什么愿意参与，又是什么让他愿意留下来。**

在蔚来，我把车主的日常变成社区话题，也尝试用路书教程帮助用户表达；在波克，我从活动反馈中寻找人物故事，再把写作方法整理成可复用的 Skill；在流利说英语，我琢磨选题、账号人设，以及内容如何走到真实的用户行动。

我喜欢有趣的想法，也在意它最后有没有被认真做完。

## 推门之后

走廊里有八个房间，可以按自己的兴趣逛。

| 房间 | 里面放着什么 |
| --- | --- |
| 客厅 | 教育经历、技能、成绩与荣誉 |
| 工作间 | 蔚来、波克和流利说的三段实习 |
| 档案室 | 社区项目、人物专访、小红书作品，以及项目背后的判断 |
| 创意工坊 | 借助 AI coding 做出来的小产品 |
| 研究室 | 调查实验、质性研究，以及可以点开的机制图 |
| 门外的田野 | 走进街区和社区之后，听到的声音、做过的事情 |
| 壁炉边 | 蔚来实习后留下的心得：说人话、做人事、讲人情 |
| 飘窗 | 工作之外的我，和几架准备飞出去的纸飞机 |

墙上的作品可以点开，牛皮纸档案里保留了项目的时间线、数据与复盘。培根也在这里，会跑过来，陪你逛一逛。

## 一些正在动手做的事

### [省钱搭子](https://kdo736699-max.github.io/moneysave/)

一个人记账容易没下文。我想试试，朋友之间的陪伴和一点游戏感，能不能让记录持续下去。于是有了三位好友的 31 天预算挑战，把消费记录、好友排行和互动道具放进同一个小产品。

### [暑性测试](https://kdo736699-max.github.io/summer/)

把关于夏天的记忆，做成十二道情境题。比起直接告诉别人“夏天是什么”，我更想让人从自己的选择里找到共鸣。

## 关于这个网站

网站使用原生 HTML、CSS 和 JavaScript，借助 AI coding 持续搭建与修改。

我希望它既能让人快速看到重点，也能在愿意多看一点的时候，找到完整的经历与思考。形式可以有趣，内容需要经得起展开。它也会随着我的新经历，慢慢长出新的东西。
