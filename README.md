# 培根的房间 · 修改说明

这是普通的静态网页，不需要数据库。源码包里的 `index.html` 是入口，其他文件和 `assets` 文件夹要一起保留。

## 自己改哪里

| 想修改的内容 | 文件 |
| --- | --- |
| 教育、成绩、技能、完整实习、四个项目、论文、田野经历 | `profile.js` |
| 六篇流利说作品的链接和说明、波克链接、各房间的排版、邮箱与手机 | `room-templates.js` |
| 房间名字、图片对应、三组运营心得、飘窗的六句话 | `content.js` |
| 新增档案墙、牛皮纸弹窗、工作间等样式 | `revisions.css` |
| 原有颜色、字体、走廊、门、小蓝等样式 | `styles.css` |
| 返回、跳转、弹窗、纸飞机和小蓝交互 | `app.js` |
| 图片 | `assets/` |

改文字时，替换引号里面的内容，保留引号、逗号、方括号。日期按 `YYYY.MM` 写，有明确日期的项目可以保留日。替换图片最简单的方法是使用同名文件；换文件名时，也要改 `content.js` 的对应路径。

## 放到 GitHub 上修改

可以。解压源码包，把包内文件上传到仓库根目录，保持 `index.html` 和 `assets/` 在同一层。以后在 GitHub 打开对应文件，编辑、提交修改即可保存版本；需要展示为网站时，再配置静态网页托管。

GitHub 上修改的是分文件源码，已经下载到电脑的单文件 HTML 不会自动同步。源码更新后，需要重新导出单文件。

## 本地打开

直接查看成品，请打开随附的 `培根的房间_改版.html`。它已嵌入图片与动画，不需要服务器。

分文件源码适合维护和托管；直接双击源码中的 `index.html`，部分浏览器会限制外部 SVG。可使用本地静态服务器预览，或查看导出的单文件。
