# 培根的房间

**你好，我是赵培涵，也可以叫我培根。**

对人的生活有好奇，对把事情做好有耐心。

这是我的个人网站，也是一间可以推门走进去的房间。我把做过的项目、写过的内容、研究过的问题，以及工作之外的自己，放在这里。

## 关于我

本科就读于华东理工大学公共事业管理专业，目前在华东师范大学攻读社会工作硕士，预计2027年7月毕业。

我做过社区运营、内容传播和公益项目，也做社会科学研究与一些小产品。对我而言，这些经历有一个共同的起点：**理解一个人为什么愿意参与，又是什么让他愿意留下来。**

在蔚来，我把车主的日常变成社区话题，也尝试用路书教程帮助用户表达；在波克，我从活动反馈中寻找人物故事，再把写作方法整理成可复用的 Skill；在流利说，我琢磨过选题、账号人设，以及内容如何走到真实的用户行动。

我喜欢有趣的想法，也在意它最后有没有被认真做完。

## 推门之后

走廊里有八个房间，可以按自己的兴趣逛。

| 房间 | 里面放着什么 |
| :--- | :--- |
| **客厅** | 我的教育经历、技能，以及一路积累的成绩与荣誉 |
| **工作间** | 在蔚来、波克和流利说的三段实习 |
| **档案室** | 社区项目、人物专访、小红书作品，以及项目背后的判断 |
| **创意工坊** | 借助 AI coding 做出来的小产品 |
| **研究室** | 调查实验、质性研究，以及可以点开的机制图 |
| **门外的田野** | 走进街区和社区之后，听到的声音、做过的事情 |
| **壁炉边** | 在蔚来实习后留下的心得：说人话、做人事、讲人情 |
| **飘窗** | 工作之外的我，和几架准备飞出去的纸飞机 |

墙上的作品可以点开，牛皮纸档案里保留了项目的时间线、数据与复盘。小蓝也在这里，会跑过来，陪你逛一逛。

## 关于这个网站

网站使用原生 HTML、CSS 和 JavaScript，借助 AI coding 持续搭建与修改。

我希望它既能让人快速看到重点，也能在愿意多看一点的时候，找到完整的经历与思考。形式可以有趣，内容需要经得起展开。

它也会随着我的新经历，慢慢长出新的东西。

## 自存修改的对应文件的注意事项

| 想修改的内容 | 文件 |
| --- | --- |
| 教育、成绩、技能、完整实习、四个项目、论文、田野经历 | `profile.js` |
| 六篇流利说作品的链接和说明、波克链接、各房间的排版、邮箱与手机 | `room-templates.js` |
| 房间名字、图片对应、三组运营心得、飘窗的六句话 | `content.js` |
| 新增档案墙、牛皮纸弹窗、工作间等样式 | `revisions.css` |
| 原有颜色、字体、走廊、门、小蓝等样式 | `styles.css` |
| 返回、跳转、弹窗、纸飞机和小蓝交互 | `app.js` |
| 图片 | `assets/` |

改文字时，替换引号里面的内容，保留引号、逗号、方括号。日期按 `YYYY.MM` 写，有明确日期的项目可以保留日。替换图片最简单的方法是使用同名文件；换文件名时，也要改 `content.js` 的对应路径。
